# Datasets

This directory contains the preprocessed datasets used for training and evaluation.

## Files

| File | Description | Features |
|------|-------------|----------|
| `train_final.csv` / `test_final.csv` | Wrapper-reduced set (RFE + Backward Elimination) | 20 |
| `train_MI.csv` / `test_MI.csv` | Mutual Information top-40 | 40 |
| `train_40.csv` / `test_40.csv` | Paper's original top-40 features | 40 |
